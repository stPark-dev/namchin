# 남친렌즈 (Namchin Lens)

> **사진 못 찍는 남자친구를 위한 카메라.**
> 화면이 구도와 포즈를 코칭하고, 여자친구가 고른 인스타 사진을 그대로 재현하도록 감독합니다.

미적 감각이 부족해서 여자친구 사진을 잘 못 찍어 주는 남편과 남자친구를 위한 안드로이드 카메라 앱입니다.
남자친구는 감각 대신 **안내만 따라가면** 됩니다. 앱이 감독이고, 남자친구는 촬영 담당입니다.

개인 프로젝트이며, 테스트 기기는 Galaxy S23 Ultra입니다. 서버 없이 모든 처리를 폰 안에서 합니다.

---

## 어떻게 쓰나

```
앱 실행 → 바로 카메라
 ├─ 기본 모드: 여자친구를 비추면 구도를 코칭
 │    "폰을 무릎 높이로 낮추고 발끝을 화면 아래에 맞추세요"
 │    "발목에서 잘려요" · "얼굴이 향한 화면 오른쪽에 여백을 두세요"
 │
 └─ 오른쪽 아래에 레퍼런스 카드 2~3장이 카드 게임 손패처럼 빼꼼
      ├─ 카드 탭 → 레퍼런스 모드: 그 사진의 구도와 포즈를 재현하도록 안내
      │    반투명 레퍼런스 겹쳐 보기, 목표 골격(흰색)과 현재 골격(노랑 → 맞으면 초록)
      │    맞는 상태가 0.5초 유지되면 자동으로 3장 연속 촬영
      └─ 위로 쓸면 → 전체 레퍼런스 펼침
```

레퍼런스는 여자친구가 인스타에서 고른 사진입니다. 카톡 등으로 받은 사진을 **공유하기 → 남친렌즈**로 넣으면 됩니다.

## 주요 기능

| 영역 | 기능 |
|---|---|
| **레퍼런스 가져오기** | 공유 인텐트 또는 사진 선택. 인스타 캡처라면 UI를 걷어낸 사진 영역을 자동으로 찾아 제안하고, 실패하면 수동으로 자릅니다. ML Kit으로 포즈를 분석해 저장합니다. |
| **기본 모드 코칭** | 수평, 관절에서 잘림(발목·무릎·손목), 머리 잘림, 다리 길어 보이게(발끝을 화면 아래에), 머리 위 여백, 시선 방향 여백(삼분할) |
| **레퍼런스 모드** | 찍힐 영역을 레퍼런스 비율로 표시, 거리·기울기·좌우 안내, 팔다리 마디 10개의 각도 비교(좌우반전 포즈도 인정), 가장 어긋난 부위 안내 |
| **피드백** | 한국어 음성 안내(이어폰 지원), 진동(안내는 "틱", 맞는 순간은 "틱틱"), 자동 셔터(3장 연속) |
| **카메라** | 핀치 줌, 0.6×·1×·3×·10× 버튼, 레퍼런스 비율로 잘라 `DCIM/남친렌즈`에 저장 |
| **설정** | 셔터음 켬/끔, 삼분할 격자 켬/끔 |

### 앞으로 할 일
- **Phase 7:** 촬영 결과를 레퍼런스와 나란히 비교하고 베스트 컷 표시 (눈 감은 컷 제외)
- **Phase 8:** 지금 배경과 비슷한 레퍼런스 카드를 앞쪽에, 태그 자동 제안과 수정
- **Phase 9:** 야경과 저조도 처리
- **2차:** 커플 투샷, 망원 렌즈 자동 안내

자세한 기획은 [docs/PLAN.md](docs/PLAN.md), 구현 순서는 [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md)에 있습니다.

## 기술 구성

| 항목 | 사용 |
|---|---|
| 언어/UI | Kotlin 2.4, Jetpack Compose (Material 3, 동적 색상) |
| 카메라 | CameraX 1.6 (Preview + ImageAnalysis + ImageCapture, 4:3) |
| 포즈 인식 | ML Kit Pose Detection Accurate (정지 이미지 / 스트림), S23 기준 프레임당 약 25~45ms |
| 저장 | Room (레퍼런스), SharedPreferences (설정), MediaStore (촬영 사진) |
| 빌드 | Gradle 9.9, AGP 9.5, compileSdk 37.2, minSdk 34 |

### 모듈 구조

```
namchin/
├── core/   순수 Kotlin. 안드로이드 의존성 없음. 판단 로직 전부 (TDD)
│   ├── pose/         포즈 일치도 (마디 각도, 이미지 비율 보정, 좌우반전)
│   ├── framing/      인물 위치·크기(어깨·골반 기준), 구도 차이 → 안내
│   ├── composition/  기본 모드 구도 규칙
│   ├── guidance/     안내 종류, 우선순위·안정화·반복 방지
│   ├── shutter/      일치 판정, 자동 셔터 상태 머신
│   ├── live/         프레임 단위 판정, 촬영 영역 좌표 변환, 기울기
│   ├── crop/         인스타 캡처 사진 영역 검출
│   ├── reference/    레퍼런스 진단 (포즈 비교 가능 여부, 거리 기준)
│   ├── tagging/      태그 추론 (학습 없는 kNN)  ← Phase 8에서 연결
│   └── bestshot/     베스트 컷 점수            ← Phase 7에서 연결
└── app/    Android. 센서·ML·카메라·화면을 core에 연결하는 얇은 층
    ├── camera/  ML Kit 스트림 분석, 기울기 센서, 음성, 진동, 줌, 피드백
    ├── capture/ 촬영 저장, 연속 촬영
    ├── importer/, data/, image/, ml/, settings/
    └── ui/      카메라(카드 손패, 오버레이), 레퍼런스 관리, 가져오기, 설정
```

## 빌드와 실행

```bash
# 테스트 (core 135개 + 앱 단위 37개)
./gradlew :core:test :core:koverVerify :app:testDebugUnitTest

# 기기 설치 (USB 디버깅 켠 폰 연결)
./gradlew :app:installDebug
```

- core는 라인 커버리지 80% 미만이면 빌드가 실패합니다(Kover).
- 기기 DB 테스트(`connectedDebugAndroidTest`)는 끝날 때 **앱을 삭제해서 앱 데이터가 지워집니다.** 실사용 데이터가 있다면 주의하세요.

## 브랜드 · 로고 · 앱 아이콘 브리프

> 이 섹션은 이미지 생성 AI(GPT 등)가 로고와 앱 아이콘을 만들 때 참고하는 지침입니다.

### 한 줄 정체성
**"사진 못 찍는 남자친구의 든든한 사진 코치"**. 여자친구를 예쁘게 찍어 주고 싶은 마음을 렌즈 하나에 담은, 귀엽고 다정한 카메라 앱입니다.

### 이름
- 한글: **남친렌즈**
- 영문: **Namchin Lens** (namchin = 한국어 "남친(남자친구)"의 로마자)
- 로고 글자는 한글 "남친렌즈"를 우선하고, 영문은 보조로 씁니다.

### 사용자와 분위기
- **사용자:** 20~30대 연인. 실제로 앱을 들고 찍는 사람은 남자친구지만, 결과물과 감성은 여자친구 취향이어야 합니다.
- **분위기:** 다정함, 약간의 유머("사진 못 찍는 남친"이라는 자기 비하 개그), 믿음직함
- **피할 것:** 전문 카메라 앱처럼 차갑고 기계적인 느낌, 과하게 유치한 느낌, 성별 고정관념을 비꼬는 느낌

### 핵심 모티프 (하나 또는 둘을 조합)
1. **카메라 렌즈(원형 조리개)**: 앱의 정체성
2. **하트**: 여자친구를 향한 마음. 예: 렌즈 안의 조리개 날이 하트 모양, 렌즈 반사광이 작은 하트
3. **구도 가이드 프레임**: 뷰파인더 네 모서리의 꺾쇠(⌜ ⌝ ⌞ ⌟), 또는 삼분할 격자. "안내해 준다"는 의미
4. **골격 가이드 선**: 관절 점과 선으로 된 단순한 인물 실루엣. 앱의 포즈 가이드 화면 그대로입니다. 쓸 경우 아주 단순하게.

추천 조합은 **렌즈 + 하트 조리개** 또는 **뷰파인더 꺾쇠 안의 하트**입니다.

### 색상 (앱 UI에서 실제로 쓰는 색)
| 역할 | 색 | 쓰는 곳 |
|---|---|---|
| 메인 포인트 | **노랑 #FFD600** | 현재 골격, 선택된 줌·토글 |
| 성공·일치 | **초록 #00E676** | 포즈가 맞았을 때 골격, 수평 맞음 |
| 경고 | 빨강 #E53935 | 레퍼런스 해제 ✕ |
| 배경 | 검정 #000000 / 흰색 #FFFFFF | 카메라 화면 배경, 테두리 |

아이콘은 **노랑을 주색**으로 하고, 검정 또는 짙은 남색과 대비시키는 것을 권장합니다. 초록은 작은 포인트(맞았다는 신호)로만 씁니다.

### 앱 아이콘 기술 조건 (Android)
- **적응형 아이콘:** 전경 + 배경 두 레이어
  - 캔버스 108×108dp (432×432px @xxxhdpi). 핵심 그림은 **가운데 66dp 원(안전 영역)** 안에
  - 기기마다 원, 둥근 사각형 등으로 잘리므로 가장자리에 중요한 요소를 두지 않음
- **모노크롬 레이어:** Android 13 이상의 테마 아이콘용. 단색 실루엣으로도 알아볼 수 있어야 함
- **작은 크기:** 48dp에서도 알아볼 수 있게 선은 굵게, 디테일은 최소로
- **아이콘 안에는 글자를 넣지 않음** (로고에만 글자)
- 플랫하거나 살짝 입체감 있는 벡터 스타일. 사진처럼 사실적인 렌더링은 피함

### 하지 말 것
- 실제 사람 얼굴이나 사진 사용
- 다른 앱이나 브랜드와 혼동되는 디자인 (특히 인스타그램 카메라 아이콘의 보라-주황 그라데이션 + 둥근 사각형 + 렌즈 조합)
- 기존 캐릭터, 마스코트, 상표 사용
- 성적이거나 선정적인 표현

### 만들어야 할 결과물
1. **앱 아이콘**: 1024×1024 PNG (스토어/미리보기용)
2. **적응형 아이콘 레이어**: 전경 432×432 투명 PNG, 배경 432×432 PNG(또는 단색 지정)
3. **모노크롬 아이콘**: 432×432 투명 PNG, 단색
4. **가로형 로고**: 심볼 + "남친렌즈" 글자, 투명 배경. 밝은 배경용과 어두운 배경용
5. **심볼만**: 정사각형, 투명 배경

## 개인정보

- 레퍼런스 이미지와 분석 결과는 **폰 안의 앱 저장소에만** 저장되고, 외부로 보내지 않습니다.
- 촬영 사진은 폰 갤러리 `DCIM/남친렌즈` 폴더에 저장됩니다.
- 인스타그램 API나 스크래핑은 쓰지 않습니다. 레퍼런스는 사용자가 직접 공유한 사진만 씁니다.
