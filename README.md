# 남친렌즈 (Namchin Lens)

> **사진 못 찍는 남자친구를 위한 카메라.**
> 화면이 구도와 포즈를 코칭하고, 여자친구가 고른 인스타 사진을 그대로 재현하도록 감독합니다.
> **구도로 찍고, 필터로 완성합니다.**

미적 감각이 부족해서 여자친구 사진을 잘 못 찍어 주는 남편과 남자친구를 위한 안드로이드 카메라 앱입니다.
남자친구는 감각 대신 **안내만 따라가면** 됩니다. 앱이 감독이고, 남자친구는 촬영 담당입니다.

개인 프로젝트이며, 테스트 기기는 Galaxy S23 Ultra입니다. 서버 없이 모든 처리를 폰 안에서 합니다.

---

## 어떻게 쓰나

```
앱 실행 → 바로 카메라
 ├─ 기본 모드: 여자친구를 비추면 구도를 코칭
 │    "폰을 무릎 높이로 낮추고 발끝을 화면 아래에 맞추세요"
 │    "발목에서 잘려요" · "얼굴이 향한 화면 오른쪽에 여백을 두세요"
 │    구도 틀을 고르면 화면에 틀이 그려지고, 맞으면 노랗게 바뀌며 진동
 │    필터를 고르면 카메라 화면에서 미리 보고 찍음
 │
 └─ 오른쪽 아래에 레퍼런스 카드 2~3장이 카드 게임 손패처럼 빼꼼
      ├─ 카드 탭 → 레퍼런스 모드: 그 사진의 구도와 포즈를 재현하도록 안내
      │    반투명 레퍼런스 겹쳐 보기, 목표 골격(흰색)과 현재 골격(노랑 → 맞으면 초록)
      │    맞는 상태가 0.5초 유지되면 자동으로 3장 연속 촬영
      └─ 위로 쓸면 → 전체 레퍼런스 펼침

찍은 뒤 → 베스트 컷 고르기 + 필터 마무리 → 필터 입힌 사진만 갤러리에 남음
```

레퍼런스는 여자친구가 인스타에서 고른 사진입니다. 카톡 등으로 받은 사진을 **공유하기 → 남친렌즈**로 넣으면 됩니다.

## 주요 기능

| 영역 | 기능 |
|---|---|
| **레퍼런스 가져오기** | 공유 인텐트 또는 사진 선택. 인스타 캡처라면 UI를 걷어낸 사진 영역을 자동으로 찾아 제안하고, 실패하면 수동으로 자릅니다. ML Kit으로 포즈를 분석해 저장합니다. |
| **기본 모드 코칭** | 수평, 관절에서 잘림(발목·무릎·손목), 머리 잘림, 다리 길어 보이게(발끝을 화면 아래에), 머리 위 여백, 시선 방향 여백(삼분할) |
| **구도 틀** | 레퍼런스 없이 고르는 틀 4종: 전신 다리 길게 · 상반신·클로즈업 · 인물 한쪽 + 배경(삼분할) · 수평선 + 인물(T자). 화면에 인물 실루엣을 그리고 거리·위치를 안내, 맞으면 노랗게 바뀌고 진동 |
| **확대 촬영** | 기본 배율(끔/2×/3×)을 정해 두면 카메라가 그 배율로 시작하고, 1×로 찍으려 하면 "한 걸음 물러나서 2배로 찍어요" 안내 (얼굴·몸 비율이 덜 왜곡되는 인물 사진 기법). 인스타 4:5 비율 저장 |
| **필터** | 8종(맑음 · 포근 · 필름 · 노을 · 청량 · 밤거리 · 흑백 · 빈티지). 찍기 전 카메라 화면에서 실시간 미리보기, 피부색은 지나치게 바뀌지 않게 보호 |
| **레퍼런스 모드** | 찍힐 영역을 레퍼런스 비율로 표시, 거리·기울기·좌우 안내, 팔다리 마디 10개의 각도 비교(좌우반전 포즈도 인정), 가장 어긋난 부위를 방향과 함께 안내("오른팔을 더 올려 달라고 하세요") |
| **"왜?" 설명** | 안내 캡슐을 누르면 그 안내의 이유 한 줄 (예: "관절에서 잘리면 팔다리가 잘려 나간 것처럼 어색해 보여요") |
| **카드 손패** | 오른쪽 아래 레퍼런스 카드를 탭하거나 길게 눌러 끌어올리면 크게 보기, "이 레퍼런스 적용"으로 카드가 왼쪽 위 칩으로 날아감 |
| **피드백** | 한국어 음성 안내(이어폰 지원), 진동(안내는 "틱", 맞는 순간은 "틱틱"), 자동 셔터(3장 연속) |
| **카메라** | 핀치 줌, 0.6×·1×·2×·3×·10× 버튼, 레퍼런스 비율(없으면 3:4 또는 4:5)로 잘라 `DCIM/남친렌즈`에 저장 |
| **설정** | 셔터음 켬/끔, 삼분할 격자 켬/끔, 기본 배율, 인스타 4:5 비율, 분석 정보 표시 |
| **베스트 컷 · 마무리** | 연속 촬영(자동 셔터 또는 셔터 길게 누르기) 후 포즈·눈 뜸·선명도로 베스트 선택, 레퍼런스와 나란히 비교. 필터 8종 또는 레퍼런스 색감을 골라 강도 조절. 마치면 고른 사진만 남기고 필터를 원본 해상도로 입혀 **필터 사진만** 남김(찍은 날짜·위치 정보 유지). 카메라에서 고른 필터가 미리 골라져 있음 |
| **장면 추천·태그** | 지금 배경과 비슷한 레퍼런스 카드를 앞으로, 자동 태그(구도·시간·장소) + 확정한 태그로 비슷한 사진에 제안, 카드 목록 태그 필터 |
| **야간** | 어두우면 포즈 비교·자동 셔터를 끄고 구도만 안내, 손떨림 경고 |

## 기술 구성

| 항목 | 사용 |
|---|---|
| 언어/UI | Kotlin 2.4, Jetpack Compose (Material 3, 동적 색상) |
| 카메라 | CameraX 1.6 (Preview + ImageAnalysis + ImageCapture, 4:3), 실시간 필터는 AGSL 셰이더(RenderEffect) |
| 색 보정 | 3D 색 변환표(LUT): 저장용 65³, 미리보기용 33³ |
| 포즈 인식 | ML Kit Pose Detection Accurate (정지 이미지 / 스트림), S23 기준 프레임당 약 25~45ms |
| 저장 | Room (레퍼런스), SharedPreferences (설정), MediaStore (촬영 사진) |
| 빌드 | Gradle 9.9, AGP 9.5, compileSdk 37.2, minSdk 34 |
| 글꼴 | 제목·버튼에 [주아(Jua)](https://fonts.google.com/specimen/Jua) ([OFL](docs/licenses/Jua-OFL.txt)) |

### 모듈 구조

```
namchin/
├── core/   순수 Kotlin. 안드로이드 의존성 없음. 판단 로직 전부 (TDD)
│   ├── pose/         포즈 일치도 (마디 각도, 이미지 비율 보정, 좌우반전)
│   ├── framing/      인물 위치·크기(어깨·골반 기준), 구도 차이 → 안내
│   ├── composition/  기본 모드 구도 규칙, 구도 틀 4종
│   ├── color/        필터 8종, 레퍼런스 색감 따라하기, 색 변환표
│   ├── guidance/     안내 종류, 우선순위·안정화·반복 방지
│   ├── shutter/      일치 판정, 자동 셔터 상태 머신
│   ├── live/         프레임 단위 판정, 촬영 영역 좌표 변환, 기울기, 확대 촬영 안내
│   ├── crop/         인스타 캡처 사진 영역 검출
│   ├── reference/    레퍼런스 진단 (포즈 비교 가능 여부, 거리 기준)
│   ├── tagging/      태그 추론 (학습 없는 kNN)
│   └── bestshot/     베스트 컷 점수
└── app/    Android. 센서·ML·카메라·화면을 core에 연결하는 얇은 층
    ├── camera/  ML Kit 스트림 분석, 기울기 센서, 음성, 진동, 줌, 피드백
    ├── capture/ 촬영 저장, 연속 촬영
    ├── review/  베스트 컷 분석, 필터·색감 입히기, 마무리(덮어쓰기)
    ├── importer/, data/, image/, ml/, settings/
    └── ui/      카메라(카드 손패, 오버레이, 구도 틀, 필터), 결과 화면, 레퍼런스 관리, 가져오기, 설정
```

## 빌드와 실행

```bash
# 테스트 (core 261개 + 앱 단위 69개)
./gradlew :core:test :core:koverVerify :app:testDebugUnitTest

# 기기 설치 (USB 디버깅 켠 폰 연결)
./gradlew :app:installDebug

# 기기 화면 테스트 (앱 데이터를 지우지 않는 방법)
./gradlew :app:assembleDebugAndroidTest
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w -e class dev.stpark.namchin.ui.review.ResultOverlayTest \
  dev.stpark.namchin.debug.test/androidx.test.runner.AndroidJUnitRunner
```

- core는 라인 커버리지 80% 미만이면 빌드가 실패합니다(Kover).

### 릴리스 빌드

```bash
./gradlew :app:assembleRelease   # → app/build/outputs/apk/release/app-release.apk (약 87MB)
```

- 저장소 루트의 `keystore.properties`가 서명 키를 가리킵니다 (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`). 이 파일과 키(`*.jks`)는 저장소에 올리지 않습니다. 없으면 서명 없는 APK가 나옵니다.
- **키 파일을 잃어버리면 같은 앱으로 업데이트할 수 없습니다.** 키와 `keystore.properties`를 따로 백업하세요.
- R8로 코드·리소스를 줄이고, arm64 폰용 라이브러리만 넣습니다 (디버그 APK는 약 314MB).
- 디버그 빌드는 `dev.stpark.namchin.debug`("남친렌즈 β")로 따로 설치되어 릴리스 앱(`dev.stpark.namchin`)과 나란히 쓸 수 있습니다. 두 앱의 레퍼런스·설정은 따로 저장됩니다.
- 예전 디버그 빌드(ID가 `dev.stpark.namchin`)가 폰에 있으면 서명이 달라 릴리스를 그 위에 설치할 수 없습니다. 지우면 그 앱의 레퍼런스 데이터도 지워지니 레퍼런스를 다시 넣을 준비를 하세요.
- `connectedDebugAndroidTest`는 끝날 때 **앱을 삭제해서 앱 데이터가 지워집니다.** 실사용 데이터가 있다면 위의 `am instrument` 방법을 쓰세요.
- 새 버전을 배포할 때는 `app/build.gradle.kts`의 `versionCode`·`versionName`을 올립니다. 배포판은 [Releases](https://github.com/stPark-dev/namchin/releases)에 있습니다.

## 개인정보

- 레퍼런스 이미지와 분석 결과는 **폰 안의 앱 저장소에만** 저장되고, 외부로 보내지 않습니다.
- 촬영 사진은 폰 갤러리 `DCIM/남친렌즈` 폴더에 저장됩니다.
- 인스타그램 API나 스크래핑은 쓰지 않습니다. 레퍼런스는 사용자가 직접 공유한 사진만 씁니다.
